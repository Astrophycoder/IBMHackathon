# Acceptance Checklist

## Complete product
- [ ] All ten navigation sections are reachable.
- [ ] Required categories, subfeatures and additional pages are present or explicitly marked deferred.
- [ ] Home quick actions navigate correctly.
- [ ] No mock/placeholder data is presented as live.

## User journeys
- [ ] Register/login and update profile/preferences.
- [ ] Publish an opportunity and apply; owner can review and update status.
- [ ] Discover talent and contact/invite.
- [ ] Publish product/service and discover/request it.
- [ ] Create/join community initiative, volunteer or donation flow.
- [ ] Skill exchange and TogetherPoints ledger work separately from money.
- [ ] Record cash/UPI payment acknowledgement without claiming verification.
- [ ] Messages and notifications are user-scoped.
- [ ] My Activity aggregates the user's actual records.

## Algorithms
- [ ] Eligibility filters run before ranking.
- [ ] Scores expose component reasons.
- [ ] Missing/empty data is handled.
- [ ] Scores are not called accuracy.
- [ ] Fuzzy search suggests corrections without silently changing queries.
- [ ] Private profiles are never exposed by recommendations.
- [ ] New profiles are not permanently buried.

## Accessibility
- [ ] Preferences are user-selected, combinable and persistent.
- [ ] No diagnosis is inferred; essential features remain available.
- [ ] Keyboard navigation, visible focus, labels and clear errors work.
- [ ] Text resizing, contrast, touch targets and reduced motion are checked.
- [ ] Loading, empty, no-results, error/retry, offline/partial and success states exist.
- [ ] Mobile layout has no unintended horizontal overflow.

## Security and release
- [ ] Server-side validation and authorisation.
- [ ] No UPI PIN/OTP/bank credentials collected.
- [ ] No fake payment verification, wallet or escrow.
- [ ] AI output cannot perform privileged actions.
- [ ] Clean setup instructions work.
- [ ] Critical journeys have actually been run and tested.
